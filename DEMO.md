# LaporAI demo evidence plan

## Three-minute video outline

1. **0:00–0:20 — Problem and boundary.** Show the fictional login, persistent unofficial label, and the statement that no real taxpayer data or credentials are accepted.
2. **0:20–0:50 — Local evidence.** Open File tax return and show the seven-step progress header. Give the BPA1 to the agent, call `upload_tax_document`, and show the visible imported status with no server request.
3. **0:50–1:25 — Shared return.** Import the bank and financing samples. Ask the agent for `review_prefilled_data`; highlight the missing asset and outdated liability returned from current page state.
4. **1:25–2:00 — Controlled mutation.** Ask the agent to update the liability. Show the exact proposal beside the form, reject it, repeat and approve it, then show `Agent` attribution and undo.
5. **2:00–2:30 — Dynamic tools.** Validate the return, open declaration, and show that add/update/remove tools disappear while `explain_tax_result` remains.
6. **2:30–2:45 — Human control.** Show that the agent cannot declare, sign, pay, or submit. Acknowledge the warning manually and create the local receipt, which states that no government submission occurred.
7. **2:45–3:00 — Evidence.** Show three benchmark modes and state that the recorded figures apply only to the disclosed fictional scenario.
